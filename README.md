# Bloomwire

A lightweight, polished landing-page demo for the Bloomwire concept.

## Run locally

From the repository root:

```bash
npm start
```

Then open:

```text
http://127.0.0.1:3000/index.html
```

## Files

- `index.html` — main page structure
- `style.css` — layout and visual styling
- `app.js` — small interactive behavior for the status button
